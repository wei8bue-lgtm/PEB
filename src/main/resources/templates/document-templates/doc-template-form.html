Template-Informationen

Attribute (Platzhalter im Template)

Verwenden Sie {{Attribute1}} und {{Attribute2}} als Platzhalter in der .doc-Datei. Diese werden beim Erstellen eines Dokuments durch die eingetragenen Werte ersetzt.

Template-Datei *

Laden Sie eine .docx-Datei hoch, die als Template dient. Die Datei kann die Platzhalter {{Attribute1}} und {{Attribute2}} enthalten.

Hinweise

  • Name ist Pflichtfeld (max. 255 Zeichen)
  • ID wird automatisch generiert (Format: DT00000001)
  • Revision 01 wird automatisch angelegt (Status: Working)
  • Nur .docx-Dateien sind erlaubt
  • Platzhalter {{Attribute1}} und {{Attribute2}} in der .doc-Datei werden beim Erstellen eines Dokuments automatisch ersetzt
  • Das Template muss zuerst freigegeben werden, bevor Dokumente daraus erstellt werden können
